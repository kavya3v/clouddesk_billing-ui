# Billing chat design

Approved direction: light support desk with navy text, teal accents, a billing
illustration, rounded chat messages, and invoice/payment/subscription starters.
Retain KRMB Desk branding, the existing n8n client, safety reminder, and truthful
disclosure that questions are answered independently.

Approaches considered: a light support desk (selected), a polished dark chat,
or an unrestricted visual redesign. Use native Streamlit controls, theme tokens,
a local SVG illustration, and narrowly scoped CSS for presentation. No external
image or font requests are needed. Starter questions submit through the same
client path as typed questions. New conversation clears the transcript.
